            - goals — перечень целей, которые должны быть достигнуты;
            - themes — перечень тем, требующих исследования для достижения целей.
            - Обновить state["goals"] и state["themes"].
        - ШАГ 3. ИССЛЕДОВАНИЕ:
            - Провести исследование по каждой теме из state["themes"] в контексте state["goals"].

            - Пошагово выполнить действия из state["plan_and_strategies"].

        - ШАГ 8. ТЕСТИРОВАНИЕ:
            - Проверить state["realization"] на соответствие каждому критерию из state["success_criteria"].
            - Результат проверки: "соответствует" / "не соответствует".
